# Console Macom

App dedicado para gestao da plataforma MACOM.

Responsabilidades previstas:

- cadastro e organizacao dos sistemas
- permissoes globais por app/modulo
- administracao de usuarios e perfis
- auditoria e configuracoes transversais

Este app deve receber, em fases, as telas administrativas que hoje nao pertencem ao dominio de estoque/TI da Central.
