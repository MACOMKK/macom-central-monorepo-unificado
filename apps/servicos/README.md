# Servicos

App multi-modulo para operacao de oficina/concessionaria. Modulos planejados: Atendimento,
Oficina, Financeiro, Estoque, Compras e RH.

Hoje apenas o modulo **Financeiro** esta implementado (era o app `pagamentos`):

- solicitacoes de pagamento (com comprovante opcional)
- aprovacao unica (gestor/admin aprova ou reprova)
- marcacao de pagamento pelo financeiro (admin)
- notificacao por e-mail a cada mudanca de status

Os demais modulos aparecem no menu como "em breve" ate ganharem backend/telas proprias.

Ver `CLAUDE.md` deste app para detalhes de papeis, backend e convencoes.
